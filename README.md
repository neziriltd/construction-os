# Construction-OS™

The operating system for construction – site management, H&S, RAMS, QA/QC, workflows, departments and staff logins in one app.

This repository is the **live Cloudflare Pages edition with logins**. Every push to `main` is published automatically by Cloudflare Pages.

**Cloudflare Pages settings:** Framework preset *None*, build command *(empty)*, build output directory `/`.
**One-time:** in the Pages project, go to *Settings → Bindings* and add a **D1 database** binding named `DB`.
Optional secrets: `SETUP_CODE`, `ANTHROPIC_API_KEY`, `AI_MODEL`, `STRIPE_SECRET_KEY`.
